# Modules

所有模块统一位于 `quickshell/modules/<id>/`。单仓库架构，无外部模块仓库。

| 模块 ID | 角色 |
|---|---|
| `audio` | 音量控制 |
| `bar` | 状态栏框架 |
| `clock` | 时钟显示 |
| `common` | 共享 Widget / TuiStyle |
| `display` | 显示设置 |
| `launcher` | 应用启动器 |
| `notification-popup` | 通知弹窗 |
| `overview` | 工作区概览 |
| `polkit` | 授权代理 |
| `power-indicator` | 电源指示 |
| `settings` | 设置中心 |
| `systray` | 系统托盘 |
| `wifi` | 网络（Wi-Fi / 蓝牙） |
| `workspaces` | 工作区管理 |
