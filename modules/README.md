# Modules

所有模块统一位于 `quickshell/modules/<id>/`。单仓库架构，无外部模块仓库。

| 模块 ID | 角色 |
|---|---|
| `bar` | 状态栏框架（共享 QML 库） |
| `common` | 共享 Widget / TuiStyle（共享 QML 库） |
| `polkit` | 授权代理（共享 QML 库） |
| `settings` | 设置中心 |
| `wifi` | 网络（Wi-Fi / 蓝牙） |
| `audio` | 音量控制 |
| `display` | 显示设置 |
| `launcher` | 应用启动器 |
| `overview` | 工作区概览 |
| `screenshot` | 截图 |
| `lock` | 锁屏 |
| `input-method` | 输入法状态 |
| `keyboard-remap` | 键盘映射 |
