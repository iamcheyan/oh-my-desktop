Voice Input v1.0.0

语音输入 — Chinese-first dictation with speculative translation pipeline.

The classic voice input extension: Chinese-first SenseVoice-small-int8 dictation through a long-lived Python daemon, ffmpeg 20 dB input boost, and a speculative-translation race pipeline (silence-detect → transcribe → translate → accept on exact source match) driven by OpenAI-compatible providers. Bar button, popup, settings page and a full settings TUI.

Features

  • Bar button + popup + settings page
  • Speech-to-text pipeline
  • Speculative translation mode
  • Global keybindings

Install

  1. Download the archive below (or clone the source repo).
  2. Extract into ~/.local/share/sumika-shell/extensions/voice/
  3. Run sumika-restart — the module is discovered at startup.
  4. Open sumika-doctor if anything looks off; core modules always win on ID conflicts.
