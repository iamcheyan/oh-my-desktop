Keyboard Remap v1.0.1

键盘重映射 — Per-device keyd profiles, Fn-row modes and a key-code inspector.

Keyboard remapping on top of keyd: per-device profiles with preset tables and custom target overrides, rendered via jq to /etc/keyd/sumika.conf and applied through pkexec/run0/sudo. Apple fn-mode (hid_apple) toggle, GTK4 KeyTest capture tool for evdev/XKB/keyd codes, and a curses settings TUI plus QML editor overlay.

Features

  • Per-device keyd profiles
  • Function-row mode switching
  • KeyTest inspector (XKB/evdev/keyd codes)
  • TUI manager + settings page

Install

  1. Download the archive below (or clone the source repo).
  2. Extract into ~/.local/share/sumika-shell/extensions/keyboard-remap/
  3. Run sumika-restart — the module is discovered at startup.
  4. Open sumika-doctor if anything looks off; core modules always win on ID conflicts.
