Screenshot v2.0.1

截图工具 — Region/fullscreen capture, OCR, reverse image search and recording.

One bar button for every capture flow: fast slurp+grim region capture to clipboard/cliphist/file, fullscreen and 3s-delayed monitor shots, a frozen-snapshot region selector with edit (satty/swappy) and pixelate-redaction, Google-Lens reverse search, multi-language PaddleOCR, and screen recording (wf-recorder / gpu-screen-recorder backends, optional audio) with live stop-bar. Coordinates bar freeze/unfreeze so popups never appear in captures.

Features

  • Fullscreen & region capture
  • Screen recording
  • Clipboard integration
  • Bar button menu

Install

  1. Download the archive below (or clone the source repo).
  2. Extract into ~/.local/share/sumika-shell/extensions/screenshot/
  3. Run sumika-restart — the module is discovered at startup.
  4. Open sumika-doctor if anything looks off; core modules always win on ID conflicts.
