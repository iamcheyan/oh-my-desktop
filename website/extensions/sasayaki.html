Sasayaki Voice Input v1.0.1

语音输入（ささやき） — Local voice dictation engine in Go with optional live translation.

Sasayaki (ささやき) is the most mature voice input path: a Go control binary embedding a Python sherpa-onnx engine, kept warm by a systemd user service over a versioned Unix-socket protocol. Push-to-talk from the bar or a global keybinding, fully offline SenseVoice/Paraformer models (SHA-256 pinned downloads), compositor-aware text paste (wtype/ydotool/xdotool, XWayland and kitty special cases), and optional OpenAI-compatible translation.

Features

  • Push-to-talk voice input
  • Fully local / offline inference
  • Go binary + QML bar button & popup
  • Settings page & popup section
  • Global keybinding integration

Install

  1. Download the archive below (or clone the source repo).
  2. Extract into ~/.local/share/sumika-shell/extensions/sasayaki/
  3. Run sumika-restart — the module is discovered at startup.
  4. Open sumika-doctor if anything looks off; core modules always win on ID conflicts.
