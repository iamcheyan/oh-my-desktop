Musubi File Backup v2.0.1

文件备份与分发 — Musubi: rsync/Samba backup and config distribution with a TUI.

SMB-share backup and sync management: configure jobs, run or schedule them, restore — from the Musubi TUI, the settings page or the bar popup. A bundled status helper feeds connection state to the bar; a polkit rule (review before installing — see project review) gates privileged mounts.

Features

  • rsync backup jobs
  • Samba share management
  • Musubi TUI manager
  • Settings page + bar popup
  • polkit integration

Install

  1. Download the archive below (or clone the source repo).
  2. Extract into ~/.local/share/sumika-shell/extensions/file-backup/
  3. Run sumika-restart — the module is discovered at startup.
  4. Open sumika-doctor if anything looks off; core modules always win on ID conflicts.
